# pdm-data-platform

A data platform that provides manufacturing data, such as sensor measurements and production orders, reliably and traceably. It serves as the foundation for maintenance and data science teams, e.g. for predictive maintenance or other AI use cases.

*Note: This is a learning project to build hands-on skills in data engineering.*

**Status:** Stage 1 in progress (local batch pipeline with DuckDB)

## Setup

Requirements: Linux or WSL2, Git, [uv](https://docs.astral.sh/uv/)

```bash
git clone git@github.com:Philipp03/pdm-data-platform.git
cd pdm-data-platform
uv sync
uv run pytest
```

## Why uv and a lockfile?

- **`pyproject.toml`** describes the project and its requirements, including the build system. It lists only the direct dependencies, as minimum versions
- **`uv.lock`** records the exact versions of all packages, direct and indirect, plus checksums. It is generated by uv, never edited by hand, and committed to the repo. Unlike a hand-maintained `requirements.txt`, it also pins indirect dependencies automatically, so every installation is identical
- **`.python-version`** pins the Python version for this project. uv and the CI read it
